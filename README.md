## 制作背景

TabiSyncは、友人との旅行計画や旅行当日の行動をスムーズにすることを目的に開発した、旅行しおり共有Webアプリです。

友人など複数人での旅行では、行きたい場所や予定、持ち物、メモなどの情報が、地図アプリ・メッセージアプリ・メモアプリなどに分散しやすいという課題があります。その結果、旅行前の計画がなかなか進まなかったり、旅行当日に「次にどこへ行くのか」「移動距離的に無理のない予定か」を確認しづらくなったりすることがあります。

そこでTabiSyncでは、旅行に必要な情報を1つのしおりとしてまとめ、メンバー全員で共有・編集できるようにしました。行きたい場所を地図上で確認できるようにすることで、予定の位置関係や移動のしやすさを把握しやすくし、旅行前の準備から当日の行動までを一貫して支援することを目指しています。

また、機能面では、実際に自分が旅行中や旅行準備中に「この機能があれば便利だ」と感じたものを中心に実装しています。例えば、旅行先やしおりの内容をもとに提案を行うAI提案機能を実装しており、旅行計画を立てる際の負担を軽減できるようにしています。

将来的には、旅程、行きたい場所、持ち物、メモ、AIによる提案機能などを統合的に管理するだけでなく、他のユーザーが作成したしおりを閲覧・参考にできる機能も追加したいと考えています。これにより、旅行の計画作成から情報収集、当日の確認までをTabiSync内で完結できるプラットフォームへ発展させることを目標としています。

## 技術選定およびその意図

### Django

バックエンドフレームワークにはDjangoを採用しました。

Djangoを選定した主な理由は、将来的にAIを活用した機能を追加することを想定しており、Pythonベースで開発できる点にあります。旅行プランの提案や、しおり内の情報をもとにしたAIコンシェルジュ機能などを実装する際に、Pythonのライブラリや外部APIと連携しやすいと考えました。

また、Djangoは認証機能、管理画面、セキュリティ対策など、Webアプリケーション開発に必要な機能が標準で充実しています。現在はログイン不要で利用できる設計にしていますが、将来的にユーザーアカウント機能や旅行履歴の管理機能を追加する際にも、拡張しやすい構成にできると判断しました。

さらに、個人開発においてもデータベース管理や管理画面の実装を効率よく行えるため、機能開発に集中しやすい点も採用理由の一つです。

### Docker / Nginx

開発環境および本番運用を意識して、DockerとNginxを使用しました。

Dockerを使用することで、アプリケーションの実行環境をコンテナとして管理し、開発環境と本番環境の差異を小さくできるようにしました。個人開発であっても、環境構築の再現性を高めることで、今後の機能追加や保守を行いやすくすることを意識しています。

また、本番環境ではNginxをリバースプロキシとして利用し、Djangoアプリケーションへのリクエストを処理しています。静的ファイルの配信やHTTPS化、リクエスト制御など、Webアプリケーションを公開する上で必要な構成を学びながら実装しました。

### GPT API

AI提案機能にはGPT APIを使用しました。

TabiSyncでは、しおりの内容や行きたい場所、持ち物、メモなどをもとに、旅行に関する提案を行うAI機能を実装しています。旅行計画では、ユーザーごとに目的地や旅行スタイル、同行者、日程が異なるため、ルールベースの提案ではなく、入力内容の文脈を理解した柔軟な提案が必要だと考えました。

GPT APIを採用した理由は、自然言語による旅行提案との相性が良く、ユーザーが入力した情報をもとに、具体的で分かりやすい文章を生成できるためです。また、任意のユーザー入力を扱う機能であるため、生成品質だけでなく、安全性や運用時のリスク管理も考慮しました。
