AIコンシェルジュを使った旅行計画の例と注意点

AIコンシェルジュは、しおりに登録した旅程・行きたい場所・持ち物・メモをもとに、チャット形式で旅行計画の相談ができる機能です。このページでは、具体的な相談例と、AIが提案した変更の適用方法、利用回数の目安、利用にあたっての注意点を紹介します。

しおりを作成する AIコンシェルジュのサンプルを見る

相談できることの例

サンプルの沖縄旅行しおりでは、次のような質問を試せます。実際のしおりでも同じように質問できます。

  • 「Day2の予定を教えて」

    登録した旅程表から、指定した日の予定を要約して答えます。

  • 「行きたい場所リストから予定を組んで」

    登録した行きたい場所をもとに、無理のない予定案を提案します。

  • 「空いている日はある？」

    旅程に余白がある日や時間帯を確認できます。

  • 「持ち物を考えて」

    旅行の内容にあわせた持ち物の候補を提案します。

提案された変更を反映する

AIコンシェルジュは、質問の内容によって旅程や持ち物リストなどの変更案を提示することがあります。変更案は自動では反映されず、内容を確認したうえで適用の操作をしたときにだけ反映されます。適用には、しおりの編集権限（編集用パスワードでの認証）が必要です。

使い方の流れ

  1. 旅程・行きたい場所・持ち物・メモを登録する

    相談に使う情報のもとになるため、事前に旅程・行きたい場所・持ち物・メモを登録しておきます。

  2. AIコンシェルジュ画面を開く

    しおりのメニューからAIコンシェルジュ画面を開きます。

  3. チャットで質問・相談する

    1回あたり60文字以内のメッセージで、旅程や持ち物について質問します。

  4. 提案された変更を確認して適用する

    必要な場合のみ、内容を確認したうえで変更を適用します。

利用回数の目安

AIコンシェルジュは既定で1日5回まで利用できます（しおりごとに変更される場合があります）。上限に達すると、日付が変わるまで利用できません。1回のメッセージは60文字以内という制限もあります。

利用時の注意点

AIコンシェルジュの回答は参考情報であり、正確性を保証するものではありません。もっともらしい誤情報（ハルシネーション）が含まれる場合があります。交通機関の時刻、料金、営業時間、予約状況などは、行動や予約の前に必ず公式情報でご確認ください。

また、回答生成のためにしおりの内容や質問文が外部AIサービスへ送信される場合があります。住所や電話番号などの個人情報は入力しないでください。詳しい条件はAIコンシェルジュ利用規約と注意事項にまとめています。利用前に必ずご確認ください。
