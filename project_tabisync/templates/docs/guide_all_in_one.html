旅程・行きたい場所・持ち物・メモを一つにまとめる使い方

旅行の準備は、旅程表、地図アプリ、メモ帳、チャットのやり取りなど情報が分散しがちです。TabiSyncは、旅程表・行きたい場所・持ち物リスト・メモを1つのしおりURLにまとめて管理できます。このページでは、それぞれの機能の役割とまとめて使うメリットを紹介します。

しおりを作成する サンプルを見る

4つの機能の役割

  • 旅程表

    日程ごとに時間・タイトル・場所・メモを登録し、日ごとのタブで切り替えて確認できます。旅程表のサンプルを見る

  • 行きたい場所

    気になる場所を優先度つきで登録し、地図上でまとめて確認できます。日程が決まっていない場所も登録でき、絞り込み・並び替えも可能です。地図のサンプルを見る

  • 持ち物リスト

    「持ち物」「お土産」「子ども用」のように用途ごとに複数のリストを作り、チェックしながら準備を進められます。持ち物リストのサンプルを見る

  • メモ

    見出しや箇条書きに対応したMarkdown形式で、下調べした情報や当日の注意点を自由に書き残せます。メモのサンプルを見る

1つにまとめるメリット

  • 別々のアプリやメモ帳、チャットのやり取りを探し回らずに、1つの共有URLで完結します。
  • 友達や家族に共有するときも、旅程・行きたい場所・持ち物・メモをまとめて同じURLで見てもらえます。
  • AIコンシェルジュが旅程・行きたい場所・持ち物・メモの内容を横断的に読み取って相談に答えられます。

使い方の流れ

  1. 旅程を入れる

    日ごとの予定を時間順に登録します。1日あたり最大15件まで登録できます。

  2. 行きたい場所を追加して地図で確認する

    気になる場所を登録し、地図上でまとめて確認します。場所ごとに「Google Mapsで開く」から経路も確認できます。

  3. 持ち物リストを作る

    用途ごとにリストを分けて、必要なものをチェックしながら準備します。

  4. メモに自由記述の情報を残す

    下調べした情報や当日の注意点をメモに残しておきます。

  5. URLで共有する

    すべてまとめたしおりのURLを、友達や家族に共有します。

登録できる件数の目安

  • 日程は最大30日間まで登録できます。
  • 1日あたりの予定は最大15件まで登録できます。
  • 行きたい場所は既定で最大30件まで登録できます。
  • 持ち物リストは最大10個まで、1リストあたり最大30項目まで登録できます。
  • メモは最大15件まで、1件あたり1,000語まで入力できます。

これらの上限は既定値であり、しおりごとに変更される場合があります。
