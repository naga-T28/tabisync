旅程・行きたい場所・持ち物・メモを一つにまとめる使い方

旅行の情報が、地図アプリ、メモ、メッセージに散らばっていませんか。TabiSyncでは、予定・行きたい場所・持ち物・メモを1つのしおりにまとめられます。全部を使う必要はありません。まず必要な機能だけ使い、あとから追加できます。

しおりを作成する サンプルを見る

4つの機能の使い分け

  • 旅程表

    日時が決まった予定を入れる場所です。集合時刻、移動、食事、宿泊などを日ごとに確認できます。旅程表のサンプルを見る

  • 行きたい場所

    まだ予定に入れていない候補を集める場所です。優先度をつけ、地図で位置関係を確認してから旅程に追加できます。地図のサンプルを見る

  • 持ち物リスト

    準備するものをチェックする場所です。「共通の持ち物」「子ども用」など、用途ごとにリストを分けられます。持ち物リストのサンプルを見る

  • メモ

    ほかの3機能に当てはまらない情報を残す場所です。見出しや箇条書きを使って、下調べや注意点を整理できます。メモのサンプルを見る

おすすめの入力順

  1. 決まっている予定を旅程に入れる

    飛行機、電車、宿泊、予約済みの店など、時間を動かしにくい予定から登録します。

  2. 行きたい場所を集める

    気になる場所を追加し、地図で位置関係を確認します。近い場所を同じ日にまとめると、移動しやすい旅程になります。

  3. 必要な持ち物を洗い出す

    共通の持ち物と個人の持ち物を分け、準備できたものからチェックします。

  4. 補足情報をメモにまとめる

    現地で確認したいことや、営業時間などの下調べを残します。住所・電話番号などの個人情報は書かないでください。

  5. URLを共有して全員で確認する

    仲間に専用URLを送り、予定の抜けや無理な移動がないか確認します。

迷ったときの使い分け例

  • 「10時に水族館を予約済み」→ 旅程表
  • 「水族館の近くで寄れそうなカフェ」→ 行きたい場所
  • 「水着と日焼け止め」→ 持ち物リスト
  • 「雨の日の候補や現地で確認すること」→ メモ
