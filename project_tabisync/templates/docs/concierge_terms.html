AIコンシェルジュ 利用規約と注意事項

本ページは、TabiSync の AIコンシェルジュ機能を利用する際の注意事項と補足条件をまとめたものです。 AIコンシェルジュを利用する前に、必ずご確認ください。

1. 回答内容について

AIコンシェルジュは、しおりに登録された旅程表、行きたい場所、持ち物、メモなどの情報、およびユーザーが入力した質問内容をもとに自動で回答します。 回答は参考情報であり、正確性、完全性、有用性、最新性、特定目的への適合性を保証するものではありません。

AIによる回答には、事実と異なる内容、不完全な説明、文脈にそぐわない提案、いわゆるハルシネーション（もっともらしい誤情報）が含まれる場合があります。 重要な判断の前には、必ず利用者ご自身で内容を確認してください。

2. 外部AIサービスの利用について

AIコンシェルジュは、GPT API などの外部AIサービスを利用して回答を生成しています。 利用者は、本機能を利用することにより、当サービスの利用規約および注意事項に加え、当該外部AIサービス提供者である OpenAI の利用規約その他関連ポリシーにも同意したものとみなされます。

なお、外部AIサービスの仕様、提供条件、処理内容等は、予告なく変更される場合があります。

3. 送信される情報について

AIコンシェルジュでは、回答生成のために、利用者が入力した質問内容に加え、しおり内に登録された旅程表、行きたい場所、持ち物、メモその他回答に必要な情報の全部または一部が外部AIサービスへ送信される場合があります。

しおり内に氏名、住所、電話番号、メールアドレス、勤務先、宿泊予約情報、同行者情報その他の個人情報または機微な情報が含まれている場合、それらの情報も回答生成に必要な範囲で送信される可能性があります。 利用者は、自らの責任において、送信して差し支えない情報のみを入力・保存してください。

4. 最終判断について

交通機関の時刻、運行状況、営業時間、料金、営業日、在庫、予約状況、天候、安全情報、災害情報、現地ルール等は変動する可能性があります。 実際の行動、移動、予約、購入、支払いその他の意思決定の前には、必ず公式情報をご確認ください。

5. 対応できない内容

AIコンシェルジュは、以下のような内容には対応できない場合があります。

  • 医療、法律、税務、投資などの高度な専門判断が必要な相談
  • 法令違反や危険行為を助長する依頼
  • 個人情報の取得、追跡、監視につながる依頼
  • 第三者の権利を侵害する依頼
  • システムの想定を超える不正利用や過度な連続リクエスト

6. 禁止事項

利用者は、AIコンシェルジュの利用にあたり、以下の行為を行ってはなりません。

  • OpenAI の利用規約、ポリシーその他外部AIサービスの定めに反する行為
  • 本規約または当サービス全体の利用規約に反する行為
  • 違法行為、危険行為、不正アクセス、迷惑行為またはこれらを助長する行為
  • 虚偽情報の入力、なりすまし、第三者の情報の無断登録
  • システムへの過度な負荷を生じさせる行為、連続投稿、スクリプト等による濫用
  • AIの制限を回避しようとする行為、プロンプトインジェクションその他運営が不適切と判断する行為

7. 違反時の措置

利用者が、OpenAI の利用規約もしくは関連ポリシー、本規約、または当サービスの利用規約に反する内容を連続して投稿した場合その他運営者が不適切と判断した場合、運営者は事前の通知なく、当該しおりの削除、AIコンシェルジュ機能の利用停止、アクセス制限その他必要な措置を講じることができます。

また、悪質な場合には、法的措置その他適切と判断する対応を行う場合があります。

8. 利用回数制限

AIコンシェルジュには、しおりごとに1日あたりの利用回数制限が設定される場合があります。 制限回数は、サービスの安定運用、品質維持、不正利用防止のために変更されることがあります。

9. 保存・記録される情報

入力した質問、しおり内の参照情報、AIの回答、利用日時、エラー情報その他必要な利用記録は、品質改善、障害調査、不正利用対策、利用状況分析のために記録される場合があります。 詳細は TabiSync 全体の利用規約およびプライバシーポリシーもあわせてご確認ください。

10. 未成年者の利用について

未成年者が本機能を利用する場合は、必要に応じて親権者その他法定代理人の同意を得たうえで利用してください。

11. 免責事項

AIコンシェルジュの回答を利用したこと、または利用できなかったことにより生じた損害、トラブル、不利益、機会損失その他一切の損害について、運営者は責任を負いません。

特に、AIコンシェルジュによる回答、提案、要約、案内または判断補助に起因または関連して、事件、事故、傷害、災害、遅延、予約不備、支払トラブル、第三者との紛争その他いかなる問題が生じた場合であっても、運営者は一切の責任を負いません。 旅行中の安全、予約、支払い、移動判断その他の最終判断は、利用者ご自身の責任で行ってください。

12. サービス内容の変更・停止

運営者は、AIコンシェルジュの仕様、利用可能回数、対応範囲、利用条件等を、事前の予告なく変更、中断、停止または終了することがあります。 これにより利用者に損害が生じた場合であっても、運営者は責任を負いません。
