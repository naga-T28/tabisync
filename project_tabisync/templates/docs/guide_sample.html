旅行しおりのサンプルと作成手順

「実際にどんなしおりができるのか先に見てみたい」という方向けに、TabiSyncのサンプルしおりと、作成から共有までの手順をまとめました。サンプルは沖縄旅行3泊4日のダミーデータで、実際の利用者のしおりではありません。

しおりを作成する サンプルしおりを見る

サンプルしおり「沖縄旅行」を見る

サンプルは、那覇空港到着から美ら海水族館・古宇利島・国際通り・アメリカンビレッジ・首里城公園を巡る沖縄旅行3泊4日のデモです。以下の5画面で、実際の旅程表と同じ見た目・操作感を確認できます。デモ画面は検索結果には表示されません（noindex設定）が、リンクから直接アクセスできます。

  • 旅程表のサンプル

    1日目〜4日目をタブで切り替えながら、時間・場所・メモを確認できます。旅程表のサンプルを見る

  • メモのサンプル

    持ち物の下調べや、水族館の混雑情報などを自由記述で残す例です。メモのサンプルを見る

  • 持ち物リストのサンプル

    「持ち物」「お土産」「子ども用」のようにリストを分けてチェック管理する例です。持ち物リストのサンプルを見る

  • 行きたい場所と地図のサンプル

    行きたい場所を優先度つきで地図上に表示し、日程や並び順で絞り込める例です。地図のサンプルを見る

  • AIコンシェルジュのサンプル

    「Day2の予定を教えて」のような質問に、旅程データをもとに答える例です。AIコンシェルジュのサンプルを見る

しおりの作成手順

サンプルと同じ流れで、自分の旅行内容に置き換えて作成できます。アカウント登録は不要です。

  1. タイトルと日程を入力する

    しおり作成ページで、旅行のタイトルと日程（最大30日間）を入力します。サブタイトルや概要は任意です。

  2. 必要に応じてパスワードを設定する

    閲覧用・編集用のパスワードをそれぞれ設定できます。設定しない場合は、URLを知っている人が誰でも閲覧・編集できます。

  3. 旅程・行きたい場所・持ち物・メモを追加する

    作成後の編集画面から、日ごとの予定、行きたい場所、持ち物リスト、メモを追加していきます。詳しくは旅程・行きたい場所・持ち物・メモを一つにまとめる使い方で解説しています。

  4. URLで共有する

    発行された専用URLをコピー、またはQRコードから共有すると、友達や家族が同じしおりを確認できます。

制限事項

  • 日程は最大30日間まで登録できます。
  • 1日あたりの予定は最大15件まで登録できます。
  • メモは最大15件まで、1件あたり1,000語まで入力できます。
  • 持ち物リストは最大10個まで、1リストあたり最大30項目まで登録できます。
  • 行きたい場所は既定で最大30件まで登録できます（しおりごとに変更される場合があります）。
  • AIコンシェルジュは既定で1日5回まで利用できます。詳しくはAIコンシェルジュ利用規約と注意事項をご覧ください。
