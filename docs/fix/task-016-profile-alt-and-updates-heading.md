# Task 016: プロフィール画像のalt文言と更新履歴ページの見出し構造を整える

- 観点: SEO / アクセシビリティ
- 優先度: Low

## 問題

- `docs/profile.html`の運営者写真が`alt="運営者プロフィール画像"`と汎用的な文言になっており、画像の内容（人物）を説明していない。
- `docs/update.html`はh1直下に十数件のバージョン更新を1つの`<ul>`で羅列しており、年別・時期別の見出し区切りがない。

## 実装指示

1. `docs/profile.html`の画像altを、例えば`alt="TabiSync運営者nagaTの写真"`のように具体化する。
2. `docs/update.html`の更新履歴を年ごと（または半期ごと）に`h2`で区切る構成へ整理する（見出しテキストの意味が通る範囲で機械的に分割しない）。

## テスト

- 画像altの変更がスクリーンリーダー・画像検索の観点で内容を説明できている。
- 更新履歴ページのh2階層が論理的（新しい年から古い年へ、またはその逆に一貫している）である。
- `pipenv run python manage.py test tabisync`が成功する。
