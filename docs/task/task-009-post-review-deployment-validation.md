## 目的

本タスクは本番設定や外部サービスへのアクセスを伴うため、必要な権限と承認を得たうえで実施する。

## 1. 本番環境の`ENVIRONMENT`を設定する

### 実施項目

- [ ] 本番環境の`.env`へ`ENVIRONMENT=production`を設定する。
- [ ] 本番の`PUBLIC_BASE_URL`が`https://tabisync.com`など実際の正規公開オリジンと一致していることを確認する。
- [ ] ステージングでは`ENVIRONMENT=staging`を設定し、`PUBLIC_BASE_URL`をステージング自身のURLにする。
- [ ] 設定反映後にDjango/Gunicornコンテナを再起動する。

### 確認方法

```bash
# 本番ではNonProductionNoIndexMiddleware由来のヘッダーが付かないこと
curl -I https://tabisync.com/

# ステージングでは全レスポンスがnoindexになること
curl -I https://staging.tabisync.com/
```

本番の公開ページで`X-Robots-Tag: noindex, nofollow`が出力されず、ステージングでは同ヘッダーが出力されることを確認する。しおり・パスワード入力など、ページ固有で元からnoindex対象のレスポンスは本番でも除外対象のままとする。

### 完了条件

- 本番公開ページが環境判定によって誤ってnoindexになっていない。
- ステージングの公開・非公開ページが一律で検索対象外になっている。
- canonical、サイトマップ、OGPのオリジンが各環境の`PUBLIC_BASE_URL`と一致する。
